# Easycars - Proyecto Frontend EDCO

Proyecto educativo de la materia **EDCO - Frontend** de la Universidad de los Andes. Es un paso a paso para aprender las tecnologías web fundamentales: **HTML**, **CSS** y **JavaScript**, construyendo de forma incremental un sitio de **renta de carros** llamado *Easycars*.

## Objetivo

Aprender los conceptos básicos del desarrollo frontend mediante la construcción progresiva de una aplicación web real. Cada clase introduce nuevos conceptos y se construye sobre el trabajo de la clase anterior.

## Estructura del proyecto

El proyecto se organiza por **ramas de Git**, donde cada clase corresponde a una rama diferente:

- `master` — Rama base del repositorio.
- `clase-2` — Trabajo correspondiente a la clase 2.
- `clase-3` — Trabajo correspondiente a la clase 3.
- `clase-x` — Cada nueva clase agrega una nueva rama siguiendo este patrón.

De esta forma se puede revisar el estado del proyecto en cualquier punto del curso cambiando de rama.

## Cómo usar el repositorio

Clonar el repositorio:

```bash
git clone <url-del-repo>
cd html
```

Listar las ramas disponibles:

```bash
git branch -a
```

Cambiar a la rama de una clase específica:

```bash
git checkout clase-3
```

Abrir el proyecto:

```bash
open index.html
```

## Tecnologías

- **HTML5** — Estructura semántica del sitio.
- **CSS3** — Estilos y diseño (se incorporará en clases posteriores).
- **JavaScript** — Interactividad (se incorporará en clases posteriores).

## El sitio: Easycars

*Easycars* es una plataforma de renta de carros que se irá construyendo a lo largo del curso. Incluye:

- Página principal con catálogo de vehículos.
- Información detallada de cada carro (marca, imagen, precio).
- Acciones sobre los vehículos (comprar, marcar como favorito).
- Navegación y secciones informativas (Inicio, Acerca de, Contacto).
